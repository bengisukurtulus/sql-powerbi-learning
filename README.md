# SQL & Power BI Learning Portfolio

This repository documents my hands-on learning journey in SQL Server, Power BI, data analysis, business intelligence, and business analysis.

## Current Environment

- SQL Server 2025
- SQL Server Management Studio 22
- Power BI Desktop
- Microsoft AdventureWorks 2025 OLTP

## Learning Roadmap

1. SQL fundamentals
2. JOINs and relational data analysis
3. CASE expressions, subqueries, and CTEs
4. Window functions
5. Power BI data modeling
6. DAX and KPI development
7. Business-oriented analytics case studies
8. Portfolio projects

## Repository Structure

- `sql/` — SQL exercises and case studies
- `power-bi/` — Power BI exercises, documentation, and screenshots
- `datasets/` — dataset notes and source documentation
- `business-analysis/` — requirements, BPMN, and case studies
- `notes/` — learning notes and weekly reflections

## Current Data Source

**Microsoft AdventureWorks 2025 OLTP**

AdventureWorks is a Microsoft sample database representing a fictional business environment with sales, customers, products, employees, purchasing, and related operational data.

> The AdventureWorks backup file itself is not stored in this repository. Only analysis scripts, documentation, and project outputs are included.

## Goal

The goal of this repository is to build practical, business-oriented analytical skills and create a portfolio for Business Analyst, IT Business Analyst, BI Analyst, and Data Analyst roles.
